First public release of AgentMux for macOS.

- One MCP server for Cursor, Claude Code and ChatGPT, plus any number of Grok bots, each with its own token, webhook and inbox
- Ask any agent from any chat, hand the answer to another agent with `then →`, and keep every conversation as its own session
- Permanent tunnels on your own Cloudflare domain (or ngrok), read-only woken agents, secrets in the macOS Keychain
- In-app updates: the sidebar shows when a newer release exists and installs it in one click, after saving a backup of your vault
